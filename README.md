## 结论范围

LC按补偿实现失配分别调节平动与偏转模态的学习驱动，保留泄漏项，不直接缩放网络输出。

理论：所列假设参数及简化30维连续模型，在两个指定静止平衡点附近的数值线性化支持局部指数稳定性。不是全部受限运动或完整数字固件的UUB证明。

实物：当前公开归档为 20、30、40、50、100、200 和 300 mm 多行程对照数据，每个行程包含 M1_BASE、M2_BLNN、M3_LCBLNN 各 10 次运行。各行程的最终主表、统计表和完整度审计见多行程实验上传包。固定调制补测仍单独作为探索性材料。

参数：随动机械称重3 kg不等于已标定等效惯性；12.445是冻结控制器历史名义系数（早期13.1×0.95），不是实测质量。其沿用配置与来源应分开说明。
