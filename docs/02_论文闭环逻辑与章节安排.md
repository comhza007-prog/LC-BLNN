# 论文闭环逻辑与章节安排

## 最终策略：A+B，B主线

前期执行分配和抗饱和是A基础，LC学习协调是B核心改进。A验证基础执行策略，B验证新增学习规则。不能以A的降幅替代LC证据，不能把E5当作分配器单独消融。详细章节分工与协议见[最终A/B对应](04_A基础与B主线对应.md)。

## 主线

执行约束造成补偿实现失配 → 提出模态学习协调 → 分析规则和局部稳定性质 → 消融检验机制 → 重复实物评价收益与代价 → 将结论限定在模型与测试工况。

本论文不是全工况稳定性保证论文。局部理论、机制分析和实验分别回答不同问题，不能互相替代。

## 参考论文的借鉴方式

参考：Yan Zhou, Yanbin Liu, Huihui Pan, Weichao Sun, “Adaptive synchronization control of a dual-drive gantry stage based on broad learning neural network considering actuator saturation”, Nonlinear Dynamics, DOI: [10.1007/s11071-026-12622-5](https://doi.org/10.1007/s11071-026-12622-5)。

借鉴其“明确同步问题—建立模型—设计控制—分析性质—比较实验”的组织方式。参考论文涉及的旋转耦合建模、RLS辨识及神经补偿不能自动算作本研究贡献；它的连续理论也不能直接移植到本方法。我们不将未完成的RLS绝对标定包装为最终模型依据。

## 章节与证据

| 部分 | 要回答的问题 | 本研究材料与范围 |
|---|---|---|

| 讨论和结论 | 何时有效、边界是什么？ | 同步证据强弱、性能取舍、模型假设、运行顺序及数字实现局限 |

## 理论和实验的连接

局部线性化只支持所列参数、简化连续模型、指定常值扰动平衡点附近。省略加速度估计器和摆率历史状态；不覆盖全数字固件或整个受限任务。相关子系统引理不能自动推出全局稳定。

主实验评价LC对普通BLNN的可重复差异；固定调制补测和仿真帮助解释机制。有限样本和权值峰值下降不能证明无穷时域稳定性。

## 结论模板

本文提出基于补偿实现失配的模态学习协调方法。性质分析说明学习调制规律及相关条件有界性，数值线性化支持所建连续模型指定静止平衡点的局部指数稳定性。仿真及重复实物对照表明，该方法在所测试工况下降低观测权值峰值，并取得一定同步收益；跟踪代价及适用范围随工况变化。

## IMRAD映射与写作顺序

IMRAD：引言；方法（建模、控制与理论）；结果（仿真和实物）；讨论（机制、代价、局限）；结论。论文稿件可分章展开，但不需要硬拆多个算法创新。

写作顺序：建模与方法 → 理论 → 仿真和实物 → 讨论 → 引言、摘要、结论。每项贡献必须指向实际推导或图表，不用答辩话术代替证据。
