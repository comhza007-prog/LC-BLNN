# 材料索引与复算说明

## 目录

- materials/01_理论分析与连续模型：最终连续模型、局部线性化脚本与结果、抗饱和引理。
- materials/02_仿真与控制配置：统一控制配置、控制器实现、统一受限算例、CSV和图；历史固定调制脚本仅作探索档案。
- materials/08_多行程实验_20_300mm：20–300 mm 多行程最终主表、统计表、固件配置、HEX 和完整度审计。
- materials/04_参数身份与对应关系：参数底册；以README说明区分机械质量、假设等效惯性和历史控制器系数。静态平衡点质量无关不等于动态稳定性质量无关。
- materials/05_正式固件与原始数据索引：算法C/H、配置及任务源码片段；不是完整Keil工程。
- materials/06_实物补测_探索性：all_attempts.csv、paired_comparisons.json及历史预设协议。协议中的offline_ready等字段是运行前快照，不是当前执行状态；实际完成情况以运行记录为准。
- 多行程原始 BIN/逐帧 CSV/LOG 保存在本地实验归档中，未上传到 GitHub。

- materials/07_A线基础实验：实验1/2的平台统计与图，实验3/4逐次及分组统计、效应表、质量检查、采集顺序、图和选取的处理/正式源文件。只作当前方法的基础支撑，不与E5合并统计。
- data/A_foundation_source_manifest.json：A线材料本地来源、归档ZIP哈希及选取成员哈希。历史说明按原样保留；当前解释以docs/04为准。

## 依赖与运行

Python依赖见requirements.txt。在仓库根目录运行：

```powershell
python "materials/01_理论分析与连续模型/local_linearization_stability_analysis.py"
python "materials/02_仿真与控制配置/run_unified_saturation_benchmark.py"
```

脚本运行会重新生成其目录内的结果；先建工作副本，再比较新结果，勿把仿真结果当作实物原件。上传前做语法、导入、局部稳定性只读复核；本次不重新生成所有仿真图，也不声称完整Keil工程可构建。

归档副本部分旧脚本含本机绝对路径/历史失败候选。不要批量执行旧脚本，不要使用其中被撤回的全局UUB断言。以本仓库docs及最终局部线性化结果限定结论。归档原来的file_manifest_and_hashes.json是本地归档前清单；GitHub链接转换后应采用根目录repository_manifest.json校验本次发布文件。

## 统计口径

多行程数据按行程分别统计，每个行程包含三个方法各10次运行。控制任务按1 ms配置，遥测标称500Hz（并非每个相邻记录都相差2ms）。补测协议为单独分支，遥测标称250Hz，不与多行程主表混同。

两类检验完整并列；报告均值/差值/置信区间和不利结果。p值不是“结果偶然概率”。补测仅2Pilot块，不作确认性显著优势结论。同步误差是电机编码器折算左右位移差，不等于独立光栅测得的刚体姿态。

## 归档完整性

原始采集BIN/CSV与第三方论文PDF未上传。GitHub中原始文件名及哈希用于追溯；持有本地原始文件者可据哈希核对。原始采集文件不修改；修正分析或解析时另存派生结果并记录理由。哈希一致只能说明和清单相同，不能单独证明采集真实性。
