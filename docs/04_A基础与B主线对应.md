# A作基础支撑，B作核心主线：最终写作安排

## 一、方向不变

A：基础同步控制、动态抗饱和与力矩优先分配；B：在共同执行框架上增加普通BLNN，再用LC协调学习。全文以LC-BLNN为核心改进，不把前期控制基础丢弃，也不将A、B包装为两篇等量算法论文。

全文链条：基础执行协调 → 补偿加入后的实现失配 → 模态学习协调 → 分层理论 → 分批实验验证。

## 二、实验职责

| 材料 | 协议/规模 | 当前论文职责 |
|---|---|---|
| 实验1 | 空载、50 mm、5次 | 平台和基础控制重复性，正文压缩呈现 |
| 实验2 | 历史2 kg附加载荷事件及50 mm、5次 | 基础载荷响应；不当作LC验证或绝对惯量辨识 |
| 实验3 | 2 kg载荷标签、10 mm；4控制条件×2限幅×5重复=40次 | C2a/C2b各自的独立限幅与SyncAlloc对照，验证执行分配的效果和代价 |
| 实验4 | 2 kg载荷标签、10 mm；2控制条件×3左右限幅×5重复=30次 | 非对称执行约束下的同步—跟踪取舍 |
| E5主实验 | 10 mm；BASE/BLNN/LC，35配对块=105次 | 在共同基础框架下评价LC相对普通BLNN的额外收益，不承担分配器独立消融 |
| E5补测 | 2个Pilot块，普通/固定/动态 | 探索性学习协调对照，独立分析，不并入105次样本 |

前四个实验的标签、窗口、参数和遥测规则保留历史事实；主实验1/2约76.9 Hz、3/4约62.5 Hz（存在更大间隔），E5标称500 Hz，补测协议标称250 Hz。不能把各批次改写为同一协议或同一采样率。3 kg是后来称量的随动机械质量；不能反向假定历史每次装配的等效惯性均已精确测得。

## 三、A线效果：只在各自协议内解释

实验3在800 counts下：C2b-SyncAlloc相对C2b，同步RMS均值下降约30.8%，跟踪RMSE下降约36.7%；C2a对应同步下降约37.6%，但控制量总变差增加约11.5%。2400 counts下饱和基本不激活，收益不一致。

实验4在1600/800下：同步RMS均值下降约38.6%，跟踪RMSE增加约5.8%，控制量总变差也增加。800/1600等其他条件收益不同，全部条件应共同报告。

以上为描述性对照结果，原采集按条件分块，并非随机化；与采集顺序相关的电压漂移等混杂不能排除。不得把30%+描述性降幅借给LC，也不得跨实验直接比较“谁的百分比更大”。

数值来源：materials/07_A线基础实验下实验3/4的效应对比CSV和分组统计CSV。历史README作为归档事实，不代替当前证据边界。

## 五、论文章节

1. 引言：执行约束下同步控制及学习补偿的研究缺口，突出LC。
2. 系统与方法：平台、模态模型、基础控制及分配（A，压缩）→BLNN和LC学习协调（B，重点）。
3. 理论性质：规则基本性质、相关子系统分析、指定30维连续模型的局部稳定性；不声称覆盖所有A/B历史分支。
4. 验证：先压缩呈现实验3/4分配与取舍，实验1/2作为平台表征；再重点写LC仿真、105次主实验及Pilot。各批协议分开列。
5. 讨论与结论：A验证基础执行策略；B评价新增学习规则；局部稳定不替代受限运动证明，实物效果不等于全局UUB。
