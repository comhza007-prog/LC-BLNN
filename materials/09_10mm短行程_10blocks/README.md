# 10 mm 短行程实验包

本目录包含 10 mm 行程、10 个配对块、30 次运行的最终主表、统计表、三套固件配置、HEX 和完整度审计。

- M1_BASE：无 BLNN、无 LC；
- M2_BLNN：普通 BLNN；
- M3_LCBLNN：BLNN + 学习协调 LC。

原始 BIN、逐帧遥测 CSV 和 LOG 保存在本地目录：
`D:\lunwen2\起重机\output\experiment5_10mm_10blocks\data_10mm_10blocks\`

这些原始文件未上传到 GitHub。`10MM_AUDIT.csv` 记录原始文件数量、完成阶段、故障字和遥测完整度。该包与 20–300 mm 多行程包分开保存，便于短行程和长行程分别统计。
