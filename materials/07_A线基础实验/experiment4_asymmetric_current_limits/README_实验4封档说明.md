# 实验4执行器不对称实验封档说明

## 封档结论

30份正式CSV全部通过检查，可以正式封档。所有运行均完整经过phase 0至6，故障码为0，控制器编号、左右电流限幅和2 kg载荷标签与文件名一致。最高逐次同步误差为0.965 mm，最高电机温度为60 ℃，未触发5 mm同步保护或80 ℃温度保护。

## 数据范围

- C2b与C2b-SyncAlloc两种方案。
- 1200/1200、800/1600和1600/800三种左右电流限幅组合。
- 每个条件5次重复，共30次。
- 固定2 kg载荷和10 mm参考行程。

## 主要结果

在1600/800条件下，SyncAlloc将同步误差RMS由0.139 mm降至0.085 mm，下降38.6%；最大同步误差均值由0.523 mm降至0.323 mm，下降38.2%；饱和样本占比由43.20%降至36.73%。与此同时，跟踪误差RMSE由0.524 mm增至0.554 mm，增加5.8%，表明同步改善伴随小幅跟踪性能折中。

## 协议偏差

预先生成的随机采集顺序没有被执行。实际数据按六个条件分组连续采集，每组连续完成5次。数据本身全部有效，但条件与采集时间存在混杂。30次运行的平均电池电压变化范围为0.061 V，采集序号与平均电压的Spearman相关系数为-0.930。论文应报告这一限制，不应将描述性差异直接表述为严格因果效应或统计显著性结论。

## 数据清洗规则

VOFA历史缓冲区可能在文件开头保留前一段数据。清洗过程依据时间、样本序号、阶段和配置字段选择最后一段配置匹配且完整经过phase 0至6的运行，并删除该片段之前的历史帧。清洗文件增加相对时间、平均位置、跟踪误差、同步误差、饱和标记和分配活动标记。原始CSV没有被覆盖。
